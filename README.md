## How to open a project

1. Install [Android Studio](https://developer.android.com/studio).
2. **File → Open** and select one folder under this repo (e.g. `android-bmi-calculator`).
3. Let Gradle sync, then Run on an emulator or device.

Some older projects may need:
- Gradle / Android Gradle Plugin updates
- SDK version bumps in `build.gradle`
- Missing `local.properties` (Studio creates this automatically)
